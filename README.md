Sunset Bay is a complete 2D top-down crime game set in the coastal city of Solmar. Across a three-job story campaign you pull off getaway drives, plan and run heists, and slip away from the police as the heat rises. Missions guide the action, a wanted system tracks how much attention you have drawn, police pursuit keeps every escape tense, and the open city is yours to drive around between jobs. It runs in a desktop browser straight from its static files, played with keyboard and mouse.

## How to play

Open `game/index.html` in a desktop browser. Drive with WASD or the arrow keys and follow the mission prompts on screen.
